예정된 휴강

단과 엑셀 올리기

러셀 시스템에서 내려받은 수강생 목록과 강좌 목록(개강일·종강일·휴강일)을 함께 고르세요. 어떤 파일인지는 자동으로 알아봐요.
강좌 목록을 올리면 단과가 개강일~종강일에만 나와요. 수강생 목록을 반영하면 기존 '단과' 스케줄은 시작일 전날까지로 끝나고 새 내용으로 바뀌어요. 담임 입력 스케줄은 그대로 남아요.

학생 태블릿에서 넣은 이동 · 교육점수예요. 잘못 넣은 기록은 지우면 관리자 페이지에서도 빠져요.

숫자를 누르면 그 칸에 들어간 학생과 이유가 나와요. 자동 숫자가 틀리면 오른쪽 [수동 입력] 칸에 더하거나 뺄 숫자(예: 2, -1)를 넣어요. 왼쪽 숫자에 바로 더해지고(✎ 표시), 개인일정은 엑셀처럼 나머지로 자동 계산돼요. 저장을 눌러야 다른 선생님에게도 보이고, 이미지에는 수동 입력 칸이 빠지고 결과 숫자만 나와요.
분류: 결석 학생 중 조퇴 이동 → 조퇴 · 단과/러셀 → 원내수업 · 학교 → 학교 · 병원·치과·진료·개인 → 스케쥴 · 그 밖의 스케줄 · 외부 학원 이동 → 원외수업 · 내부 학원 · 튜터 → 원내수업 · 병원 · 가족 행사 이동 → 스케쥴 · 식사 · 상담 등 원내 이동 → 자습 · 설문 · 기타 이동 → 개인일정 · 사유 없음 → 결석. 이동은 복귀안함이어도 사유대로 나눠요.

마감보고 엑셀

전날 마감보고 엑셀(.xlsx)을 고르면 총인원 기준일 · 입학/퇴원 목록, 명렬표, 신규 · 퇴원 누적만 오늘 내용으로 바꾼 새 파일을 내려받아요. 다른 시트 · 수식 · 서식은 그대로예요. 먼저 [명렬 갱신]으로 구글 시트 내용을 가져오세요.

누르면
칸을 누르면 +1 · 길게 누르거나 오른쪽 클릭하면 −1 · 교시별 보기에서는 − / + 버튼 · 하루 3회 이상 경고 · 7회 이상 강제하원 · 3회마다 교육점수 1점회색 점 = 구글 시트에서 넣은 기록 (여기서 줄일 수 없어요)

지각 = 출결 지각 · 태블릿 지각 (하루 1점) · 미등원 문자 2번 = 무단지각 5점 · 3번 = 무단결석 7점 (같은 날은 큰 것 하나만) · 취침 하루 3회마다 1점 · 7점 이상 항목(핸드폰 · 전자기기 · 무단이탈 · 무단결석)은 누적, 나머지는 매월 1일 초기화점수 칸: 이번 달 다음에 누적(보라색) · 학생을 누르면 내역과 제외

시트에서 퇴원 처리되어 명렬에서 빠진 학생이 자동으로 모여요. 학생을 누르면 출결 · 교육점수 기록을 볼 수 있어요. 지난 날짜 출결 화면에서도 그날 자리에 퇴원 표시로 나와요.
